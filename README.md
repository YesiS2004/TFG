# TFG
Trabajo Final de Grado
## Objetivo del proyecto
Diseñar y desarrollar un sistema de gestión de clientes, turnos y repuestos para talleres mecánicos
de Colonias Unidas

## Entorno de programación y tecnologías

Lenguaje de programación: Python(v 3.14.7)
Framework: Django
Frontend: HTML, CSS, JavaScript
Base de datos: PostgreSQL
IDE: Visual Studio Code
